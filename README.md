# immunobiology-cross-reactive-pairs
write_cross_reactive_pairs_table.R have a function which find cross reactive pairs from a netMHCpan output. It outputs a csv file of cross reactive pairs.

pairs_SARS_CoV2_other_corona.R used above function for a netMHCpan of several human corona virusses (including SARS-CoV2) to find all cross reactive pairs of
of SARS-CoV2 with several other corona virusses.

frequencies_oddsratio_cross_reative_pairs.R was used to use Augusto et al. found frequencies to find the frequencies of the allotypes which correspondences to 
a cross reactive pair.
